# Data Dictionary (features_v1 & features_v2)

Defines all feature tables generated by Member 1 for all four risk types across the smartphone supply chain prototype.

Time Window: **2025-04-01 to 2025-10-31** (214 days).  
Splits:
- `train`: 2025-04-01 to 2025-08-24 (146 days)
- `purge`: 2025-08-25 to 2025-08-31 and 2025-09-24 to 2025-09-30 (14 days)
- `val`: 2025-09-01 to 2025-09-23 (23 days)
- `test`: 2025-10-01 to 2025-10-31 (31 days; labels valid 2025-10-01 to 2025-10-24)

---

## 1. features_supplier_v1.parquet & features_supplier_v2.parquet

One row per supplier per day (`SUP001` - `SUP008`).

| Column | Type | Range / Values | Description | Leak-Free Rule |
|---|---|---|---|---|
| `entity_type` | string | "supplier" | Entity type identifier | Static |
| `entity_id` | string | SUP001-SUP008 | Supplier unique ID | Static |
| `date` | string | 2025-04-01 to 2025-10-31 | Date of feature observation (day $t$) | Calendar |
| `split` | string | train, purge, val, test | Split label | Fixed calendar bounds |
| `supplier_delay_7d_avg` | float | $\ge 0.0$ | Past 7-day average delivery delay (days) | Shifted by 1 day (`s.shift(1).rolling(7)`) |
| `rain_7d_sum` | float | $\ge 0.0$ mm | Past 7-day cumulative precipitation at supplier location | Shifted by 1 day |
| `news_tone_14d_trend` | float | -10.0 to +10.0 | Past 14-day rolling mean sentiment tone | Shifted by 1 day |
| `single_source_flag` | integer | 0 or 1 | 1 if supplier is sole provider of a key component | Static master attribute |
| `label_7d` | float | 0.0, 1.0, NaN | Supplier failure occurs in $(t+1, t+7]$ | Future outcome; NaN for $t >$ 2025-10-24 |
